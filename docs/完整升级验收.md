# 跨设备 Agent 协作升级验收

主电脑运行服务端和本机客户端，副电脑运行客户端。程序提供中文 Web 管理界面和 Agent 可调用的 MCP 工具；数据仍以 Board 服务端为准，固定执行使用 Dagu。

本轮验收必须覆盖：

1. 设备主动连接，展示真实心跳、环境和工具能力；离线不触发重复执行。
2. Codex / Claude Code / 通用 MCP Agent 注册独立会话、声明项目、认领任务和汇报进度。
3. 在同一授权项目内联系 Agent，保存消息线程、送达状态和确认记录；越权请求被拒绝。
4. 创建无需 Git 的协作任务，记录目标、范围、约束、验收标准；原子认领、阻塞、交接、提交证据、人工验收。
5. 接收方确认交接后沿用原任务，创建新的执行尝试；旧执行不能覆盖新执行的结果。
6. 通过 Dagu 调用目标设备的环境检查、目录检查和已有 Agent；明确本机授权和运行模式。
7. 复用现有知识接口，保留来源和版本，并可将结果证据关联到任务。
8. 中文界面实际验证设备、Agent、任务、消息、知识查询和交接流程；不展示虚构在线设备。
9. 重启和网络中断后保留任务、消息与结果，重发结果能去重，未知状态保持待核实。
10. 保持旧本地 Board 和 v1 网络接口兼容；主分支、中文提交、Windows 启动和更新指南。

Windows 原生实机验收按用户已有决定，在设备具备连接条件后进行；本轮须交付相应客户端并在本机独立进程验证协议闭环，清楚标明两者区别。
