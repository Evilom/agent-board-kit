# 0.4.1 连接恢复与跨设备结果验收

验证日期：2026-09-20。关联 Mac 基础设施任务 `work-5d168143cfe6400eb99300db2db5ae91`。

## 当前结论

Windows 身份已经成功请求 Mac 读取 MyWeb 上下文并执行图片检查。Mac 已运行 0.4.1。Windows 同时存在 0.3 与 0.4 客户端心跳，需要停止旧实例后升级；不能宣布所有设备已稳定、双向打通。

## 修复

- 服务增加操作系统单实例锁与可读的进程所有者记录。
- 竞争资源执行器等待接管，等待期间不再发布心跳或覆盖资源目录。此前它会退出工作线程，但设备进程继续发心跳。
- 服务进程消失后，设备子进程通过父进程管道关闭停止，取消本地执行并释放锁；不依赖 Windows 的 SIGTERM 行为。
- Hub 记录近期连接，识别同一设备重叠的不同版本或运行实例；网页显示需要处理的连接冲突。
- 请求端对收到的结果提交 SHA256 确认。只允许原请求身份确认，Mac 不能代 Windows 确认。
- 新增 `ecosystem-check`，复用原配对、目录和凭据引用，输出发现、上下文、指定命令和结果取回的实际证据。
