## 联调中修复的实际问题

- Dagu 的远程执行环境不保留客户端 Python 模块路径：改为使用经过设备凭据认证、由设备上报的运行路径，执行端再次核对本机统一配置。
- 已明确失败但缺少 stdout 的执行：保留后端失败状态和诊断，不长期显示未知。
- 本机 PATH 中的 Codex 0.137.0 不支持当前模型：保持全局工具和模型配置，新增 `agent_commands` 指向本机现有新版本。
- 浏览器重试、服务重启、窗口刷新不会重复投递消息或启动已经发出的执行。
- Windows PowerShell 脚本使用 UTF-8 BOM，Python 协议与执行回执明确使用 UTF-8。
